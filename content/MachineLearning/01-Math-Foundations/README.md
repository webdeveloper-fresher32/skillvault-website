# Phase 1: Math Foundations

> **Pillar 1 of 7: Math Foundations** — Linear Algebra, Calculus, Probability & Statistics

## What You'll Learn

The practical mathematical intuition behind vectors, matrices, dot products, derivatives, gradients, the chain rule, and probability distributions — translated directly into Python and NumPy code without unnecessary academic bloat.

## Learning Objectives

- Master vector operations, matrix multiplications, transpositions, and the geometric meaning of high-dimensional embeddings and cosine similarity.
- Understand derivatives, partial derivatives, the gradient vector, and how the calculus chain rule provides the exact mathematical foundation for neural network backpropagation.
- Build linear regression from scratch in Python and NumPy by computing forward predictions, loss functions, gradients, and parameter updates by hand.
