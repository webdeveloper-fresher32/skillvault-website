# Phase 3: Deep Learning

> **Pillar 3 of 7: Deep Learning** — PyTorch, Neural Networks, Backpropagation

## What You'll Learn

Why neural networks exist to learn hierarchical feature representations directly from raw data, how activation functions introduce non-linearity, how loss functions and Adam optimization drive training, and how to build and train deep networks using PyTorch tensors and autograd.

## Learning Objectives

- Master neural network building blocks: artificial neurons, perceptrons, forward propagation, and non-linear activations (ReLU, Sigmoid, Softmax).
- Understand loss functions (MSE, Cross-Entropy), automatic differentiation, backpropagation, and modern adaptive optimizers (Adam, AdamW).
- Build production models using PyTorch (`torch.nn`, `Dataset`, `DataLoader`, GPU acceleration), and understand sequence and spatial predecessor architectures (CNNs, RNNs, LSTMs, GRUs).
