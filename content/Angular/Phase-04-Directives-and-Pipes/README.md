# Phase 4: Directives & Pipes

## What You'll Learn

Learn how Angular lets you manipulate the DOM declaratively with directives, and transform display data declaratively with pipes. You'll master the modern `@if`/`@for`/`@switch` control-flow syntax, write your own attribute and structural directives, and build custom pipes for reusable data formatting.

## Learning Objectives

- Use built-in structural and attribute directives, including the modern `@if`/`@for`/`@switch` control-flow blocks
- Understand the difference between structural directives (which change DOM structure) and attribute directives (which change appearance/behavior)
- Write custom attribute directives using `@Directive`, `HostListener`, `HostBinding`, and `Input`
- Write custom structural directives using `TemplateRef` and `ViewContainerRef`
- Write custom pipes with `@Pipe`/`PipeTransform`, and understand pure vs impure pipes and their change-detection cost
