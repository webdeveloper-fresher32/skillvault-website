# Phase 3: Components & Templates

## What You'll Learn

Dive into Standalone Components — the fundamental building block of modern Angular apps — and learn how to bind data between a component's class and its template, plus how components pass data and events up and down the component tree.

## Learning Objectives

- Build a Standalone Component and explain its anatomy (class, template, styles)
- Configure the `@Component` decorator's metadata (`selector`, `standalone`, `imports`)
- Apply interpolation, property binding, and event binding in templates
- Use the new control flow syntax (`@if`, `@for`) to render templates conditionally and in loops
- Pass data from parent to child with `@Input()` / `input()` signals, and emit events from child to parent
