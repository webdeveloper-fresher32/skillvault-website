# Phase 7: Forms

## What You'll Learn

Build and validate forms the Angular way. Focus primarily on Reactive Forms — the API you'll use in real production apps — with enough Template-Driven Forms knowledge to read legacy code and know when the simpler approach is actually the right call.

## Learning Objectives

- Build reactive forms with `FormControl`, `FormGroup`, `FormBuilder`, and `FormArray`
- Read and write form state, and react to changes via `valueChanges` / `statusChanges`
- Build simple forms with `ngModel` and understand when template-driven forms are appropriate
- Apply built-in and custom validators, including async and cross-field validation
- Display validation errors correctly and build a real-world multi-field form with password-match validation
