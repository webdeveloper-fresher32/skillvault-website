# Phase 6: Routing & Navigation

## What You'll Learn

Wire up client-side navigation with the Angular Router. Configure routes for standalone components, read route and query parameters, navigate programmatically, lazy-load feature areas, protect routes with functional guards, and pre-fetch data with resolvers before a route activates.

## Learning Objectives

- Configure the Router with `provideRouter` and a standalone `Routes` array
- Navigate declaratively with `RouterLink` and render matched routes with `RouterOutlet`
- Read route parameters, query parameters, and navigate programmatically via the `Router` and `ActivatedRoute` services
- Lazy-load standalone components and child route groups with `loadComponent` / `loadChildren`, and protect routes with functional guards (`CanActivate`, `CanDeactivate`)
- Pre-fetch data with functional resolvers and structure nested/child routes with named outlets
