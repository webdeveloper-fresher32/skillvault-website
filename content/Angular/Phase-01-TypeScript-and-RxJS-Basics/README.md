# Phase 1: TypeScript & RxJS Basics

## What You'll Learn

Angular is built on TypeScript and RxJS, so before touching a single Angular file you'll shore up the language features and reactive patterns the framework leans on every day — typing, classes, generics, Observables, and the operators used to transform async data streams.

## Learning Objectives

- Type component state, API responses, and function signatures using interfaces, unions, and generics
- Use TypeScript classes and access modifiers the way Angular components and services do
- Explain the difference between a Promise and an Observable
- Create Observables with common RxJS creation functions (`of`, `from`, `interval`)
- Subscribe to Observables and handle `next`, `error`, and `complete` callbacks
