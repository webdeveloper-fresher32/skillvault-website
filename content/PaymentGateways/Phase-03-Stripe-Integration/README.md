# Phase 3: Stripe Integration

## What You'll Learn

Apply the general concepts from Phases 1-2 to Stripe specifically: create PaymentIntents and Checkout Sessions, mount Stripe Elements to collect card details without touching your server, and verify/handle Stripe webhooks using Stripe's own signature-verification helper.

## Learning Objectives

- Create PaymentIntents and Checkout Sessions, and know when to reach for each
- Integrate Stripe Elements as the client-side half of PCI scope reduction
- Verify and handle Stripe webhooks correctly, including local testing
