# Next.js Projects

To master Next.js, you must apply the concepts learned in the 12 phases to real-world applications. These projects are designed to scale in complexity, starting with static rendering and moving towards full-stack data mutations and authentication.

## Project List

| Project | Difficulty | Key Concepts Covered |
|---------|-----------|----------------------|
| **01. Personal Portfolio** | Beginner | Routing, Components, Styling, Metadata |
| **02. Markdown Blog** | Intermediate | Dynamic Routing, Server Components, `fs` Module, Static Generation |
| **03. E-Commerce Storefront** | Advanced | Data Fetching, Caching, Error Boundaries, Suspense |
| **04. Full-Stack Task Manager** | Expert | Server Actions, Middleware, PostgreSQL Database, Auth |

We recommend completing them in order, as each project builds on the Next.js features introduced in the previous one.
