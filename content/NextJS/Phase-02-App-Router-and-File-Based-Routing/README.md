# Phase 2: App Router and File-Based Routing

## What You'll Learn

Go beyond the shallow `app/` folder preview from Phase 1 into the App Router's full routing model — special files and nested layouts, dynamic segments and route groups, and the parallel/intercepting route patterns that power modal-style UIs.

## Learning Objectives

- Use special files and nested layouts correctly
- Work with dynamic segments and route groups
- Understand parallel and intercepting routes
