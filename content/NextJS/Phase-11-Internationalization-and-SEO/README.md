# Phase 11: Internationalization and SEO

Next.js provides powerful, built-in features to optimize your application for search engines (SEO) and to serve your content to users in multiple languages (Internationalization or i18n).

Because Next.js renders HTML on the server by default (Server Components), web crawlers and social media scrapers can easily read the metadata and content of your pages without executing JavaScript.

## Learning Objectives

By the end of this phase, you will learn how to:
- Define static and dynamic Metadata (title, description, Open Graph tags) for SEO.
- Generate standard SEO files like `sitemap.xml` and `robots.txt` dynamically.
- Implement Internationalization (i18n) routing in the App Router to support multiple languages and locales.

## Files in this Phase

1. `01-Nextjs-Metadata-API.md`: Managing `<head>` tags using the Metadata API.
2. `02-Sitemaps-and-Robots-txt.md`: Generating essential SEO files using special file conventions.
3. `03-Internationalization-i18n.md`: Setting up middleware and routing for multi-language applications.
