# Phase 2: Variables

## What You'll Learn

Store and manipulate data in scripts using variables, understand quoting rules, and use Bash's built-in special variables.

## Learning Objectives

- Declare and use variables
- Understand quoting (single vs double)
- Use special variables (`$?`, `$$`, `$#`, `$@`)
- Perform string operations and arithmetic
