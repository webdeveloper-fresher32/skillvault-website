# Phase 1: Number Systems and Simplification

## What You'll Learn

Build the foundation every other aptitude topic sits on: fast divisibility checks, unit-digit shortcuts, HCF/LCM, and exam-speed simplification of BODMAS and fraction expressions.

## Learning Objectives

- Apply divisibility rules and unit-digit shortcuts
- Compute HCF/LCM by both the prime-factorization and division methods, and use the HCF × LCM = product relationship
- Simplify BODMAS and fraction expressions at exam speed
