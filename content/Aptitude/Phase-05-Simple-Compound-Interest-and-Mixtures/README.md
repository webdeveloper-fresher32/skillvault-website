# Phase 5: Simple/Compound Interest and Mixtures

## What You'll Learn

Build speed and accuracy on simple interest (SI) and compound interest (CI) — the flat SI = PRT/100 formula versus CI's interest-on-interest growth — and learn the CI−SI difference shortcut that turns a two-step calculation into a one-line lookup. Extend the same compounding logic to half-yearly and quarterly compounding, where the trap is always in correctly splitting the rate and the number of periods. Then shift to mixtures and mensuration basics: the replacement/dilution formula for repeated removal-and-replace operations, and the small set of area, perimeter, and volume formulas (rectangle, square, circle, triangle, cube, cuboid, cylinder) that actually appear in aptitude rounds.

## Learning Objectives

- Compute SI and CI directly from the formulas, and apply the CI−SI 2-year difference shortcut, P(R/100)², in both directions (find the difference, or find the principal)
- Correctly set up half-yearly and quarterly compounding by splitting both the rate and the number of periods, and compute the equivalent effective annual rate
- Apply the mixture-replacement formula, Final = Initial×(1 − removed/total)^n, for repeated dilution problems
- Compute basic area, perimeter, and volume (rectangle, square, circle, triangle, cube, cuboid, cylinder) quickly and correctly under time pressure, including path-around-a-field problems solved as a difference of areas
