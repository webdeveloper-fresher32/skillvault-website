# Phase 11: Grammar and Sentence Correction

## What You'll Learn

This is the first Verbal Ability phase (Phases 11–12), following the six Quantitative phases (1–6) and the four Logical Reasoning phases (7–10). Verbal questions test a different skill entirely: instead of computing an answer, you catch a small, specific violation hidden inside a fluent-sounding sentence, under the same tight time pressure as every other section. This phase starts with the five grammar-rule families tested most often — subject-verb agreement, tense consistency, articles, prepositions, and parallelism — then builds on them with the two exam formats that test those rules directly: error-spotting (find the flawed part of a split sentence) and sentence correction (pick the rephrasing that fixes it), plus three additional logic-based trap categories — redundancy, misplaced modifiers, and faulty comparison.

## Learning Objectives

- Apply the five core grammar rules — subject-verb agreement, tense consistency, articles, prepositions, and parallelism — accurately and quickly enough to hold up under exam time pressure
- Use the underline-and-scan method to work through error-spotting questions in a fixed, five-checkpoint order instead of re-deriving grammar logic from scratch on every sentence
- Eliminate wrong options systematically in sentence-correction questions — discarding choices that keep the original error, that fix it but introduce a new one, or that change the sentence's meaning — until only the correct rephrasing survives
