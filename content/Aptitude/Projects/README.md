# Aptitude Course — Mock Tests

This section contains five full-length mock tests that simulate the real exam experience — mixed-topic, time-boxed, and answer-keyed. Unlike the phase lesson files (which drill one topic at a time with per-question timers), a mock test throws every topic covered so far at you together, under a single overall clock, exactly the way the real test does.

## Structure of Every Mock Test

Each mock test has **30 questions**, split in the same proportion as the course's own phase weighting:

| Section | Topic Area | Questions | Maps to |
|---|---|---|---|
| A | Quantitative Aptitude | 15 | Phases 1–6 |
| B | Logical Reasoning | 10 | Phases 7–10 |
| C | Verbal Ability | 5 | Phases 11–12 |

That's a 15:10:5 split (i.e. 50% / 33% / 17%) — the same ratio the 12-phase course itself is built on (6 Quant phases : 4 Reasoning phases : 2 Verbal phases).

**Time limit:** 30 minutes per test — roughly **1 minute per question** on average. This deliberately mirrors real competitive-exam pacing, where you don't get to spend 60–90 seconds per question the way the phase practice sets allow; you have to triage, skip, and come back. Treat the 30-minute clock as hard — stop when it runs out, then grade yourself.

**Answer key:** every mock test ends with a full `## Answer Key` covering all 30 questions — the correct option plus a one-line solution note, so you can check your work and see *why* an answer is right, not just *what* it is.

## When to Attempt Each Test

Mock tests are gated behind course progress, not handed out all at once — each one assumes you've actually finished the phases it draws from:

| # | When to Attempt | Reasoning |
|---|---|---|
| Mock Test 1 | After Phase 6 | All of Quant is done; Reasoning/Verbal sections are a light foundational preview only |
| Mock Test 2 | After Phase 8 | Adds Series, Coding-Decoding, Blood Relations, Puzzles, Seating Arrangement, Direction Sense |
| Mock Test 3 | After Phase 10 | Adds Syllogisms, Logical Deduction, Data Sufficiency, Non-Verbal Reasoning |
| Mock Test 4 | After Phase 12 | Full syllabus check #1 — every phase is fair game |
| Mock Test 5 | After Phase 12 | Full syllabus check #2 — a second full-length pass with fresh questions |

Because Mock Test 1 is attempted before Phases 7–12 are studied, its Section B and Section C questions are intentionally kept to foundational, common-knowledge-level reasoning and grammar (basic series, basic coding-decoding, basic sentence correction) — a diagnostic preview, not a test of techniques you haven't been taught yet. From Mock Test 2 onward, Sections B and C draw on the specific tools each phase has actually taught by that point.

## How to Use These

1. Set a real 30-minute timer — no pausing, no notes.
2. Attempt all 30 questions, skipping and returning as needed (just like the real exam).
3. Stop the moment the timer hits zero.
4. Grade against the Answer Key at the end of the file.
5. Review every question you got wrong (or guessed) by going back to the relevant phase lesson before moving on.

**Interpreting your score:** these mocks are unscored practice — there's no official pass mark, and negative marking (common in some real exams) isn't simulated here, so grade purely on raw correct-out-of-30. As a rough guide: **24+/30 (80%)** means you're at real-exam pace and accuracy for that section's syllabus — move on. **18–23/30 (60–75%)** means the concepts are there but speed or a specific topic is shaky — redo the phase lessons for whatever you missed before the next mock. **Below 18/30** means don't attempt the next mock yet — go back through the relevant phases properly first; a low score this early just means you moved to the mock before the underlying phases were solid, not that the material is too hard.
