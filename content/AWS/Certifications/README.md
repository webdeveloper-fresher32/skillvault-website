# AWS Certifications Overview

AWS offers certifications across four levels and multiple specialties. This directory covers everything you need to plan your certification journey.

## Certification Tiers

```
FOUNDATIONAL (no prerequisites)
└── Cloud Practitioner (CLF-C02)

ASSOCIATE (recommended: 1+ year experience)
├── Solutions Architect Associate (SAA-C03)  ← Most valuable
├── Developer Associate (DVA-C02)
└── SysOps Administrator Associate (SOA-C02)

PROFESSIONAL (required: associate cert)
├── Solutions Architect Professional (SAP-C02)
└── DevOps Engineer Professional (DOP-C02)

SPECIALTY (deep domain knowledge)
├── Advanced Networking (ANS-C01)
├── Security (SCS-C02)
├── Machine Learning (MLS-C01)
├── Database (DBS-C01)
└── Data Analytics (DAS-C01)
```
