# AWS Quick Reference

Fast-access reference sheets for AWS services, numbers, interview prep, and system concepts.

## Files

| File | Contents |
|------|---------|
| `AWS-Services-Cheatsheet.md` | All major AWS services organized by category with descriptions and use cases |
| `Key-Numbers-Limits.md` | Important limits, quotas, and numbers to memorize for exams and interviews |
| `Interview-Questions-Master.md` | 60+ interview questions with detailed answers, organized by difficulty |
| `Networking-Cheatsheet.md` | CIDR tables, ports, Security Groups vs NACLs, VPC architecture |
| `Linux-Commands-Cheatsheet.md` | Essential Linux commands for AWS engineers with examples |

## How to Use This Directory

- **Before an interview:** Review `Interview-Questions-Master.md` and `Key-Numbers-Limits.md`
- **Daily reference:** `AWS-Services-Cheatsheet.md` for quick service lookups
- **Architecture work:** `Networking-Cheatsheet.md` for CIDR/subnet planning
- **EC2 work:** `Linux-Commands-Cheatsheet.md` for common server tasks
