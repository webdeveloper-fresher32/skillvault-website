# Phase 1: Kubernetes Fundamentals

## What You'll Learn

Understand what Kubernetes is, why it was created, and how it solves the problems of running containers at scale. Get your local Kubernetes environment running and learn how Kubernetes compares to Docker Swarm so you can choose the right tool for any use case.

## Learning Objectives

- Explain what Kubernetes is and the problem it solves
- Understand core Kubernetes objects: Pod, Deployment, Service
- Install and configure a local Kubernetes cluster (minikube or kind)
- Configure kubectl and connect to your cluster
- Compare Kubernetes and Docker Swarm across architecture, features, and use cases
