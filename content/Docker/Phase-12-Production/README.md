# Phase 12: Docker in Production

> CI/CD pipelines, Kubernetes fundamentals, and production-grade Docker practices.

---

## Overview

This phase bridges the gap between containerised development and real-world deployment. You will learn how to integrate Docker into automated CI/CD workflows, get hands-on with Kubernetes as the leading container orchestration platform, and apply the best practices that make Docker workloads reliable, secure, and maintainable in production environments.

**Estimated Time:** 1 week

## What You Will Learn

### 01 — CI/CD Integration
Automate your Docker build, test, and push pipeline using tools like GitHub Actions, GitLab CI, or Jenkins. Cover image tagging strategies, registry authentication, and rolling deployments triggered by code pushes.

### 02 — Docker and Kubernetes
Understand how Kubernetes orchestrates containers at scale. Topics include Pods, Deployments, Services, ConfigMaps, and how Docker images flow into a Kubernetes cluster. Hands-on with `kubectl` and local clusters via Minikube or Kind.

### 03 — Production Best Practices
Harden your Docker setup for production: minimal base images, multi-stage builds, secrets management, resource limits, health checks, logging strategies, and monitoring hooks.
