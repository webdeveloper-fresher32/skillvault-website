# Phase 6: Docker Compose

## What You'll Learn

Manage multi-container applications as a single unit using Docker Compose. Define all your services, networks, and volumes in one file and bring everything up or down with a single command — in both development and production environments.

## Learning Objectives

- Write Docker Compose files from scratch
- Define and configure services, networks, and volumes
- Understand how Compose handles service dependencies and startup order
- Use Compose effectively in development workflows (hot reload, overrides)
- Deploy multi-container applications to production with Compose
