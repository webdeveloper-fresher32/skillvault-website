# Phase 3: Containers

## What You'll Learn

Understand the Docker container lifecycle from creation to removal. Learn how to run containers with the key runtime flags, exec into running containers, and manage container state effectively.

## Learning Objectives

- Run containers with all key flags (`-d`, `-it`, `-p`, `-v`, `--name`, `--rm`, `--env`)
- Exec into running containers to inspect or debug
- Manage the full container lifecycle: start, stop, restart, and remove
- Understand container states (created, running, paused, stopped, dead)
