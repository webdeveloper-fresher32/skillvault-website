# Phase 3: Amazon S3 Storage

## What You'll Learn

How Amazon Simple Storage Service (S3) operates, bucket and object concepts, and how to write Node.js code to perform CRUD operations, configure lifecycle policies, generate pre-signed URLs, and host static sites entirely on local emulation.

## Learning Objectives

- Explain S3 storage key-value concepts, bucket name constraints, and object structure.
- Upload, download, list, and delete objects using the AWS CLI and AWS SDK locally.
- Implement object versioning and lifecycle policies on local mock buckets.
- Generate secure pre-signed URLs using the S3 client to enable secure file transfers without access keys.
- Configure local S3 static website hosting for web applications.
