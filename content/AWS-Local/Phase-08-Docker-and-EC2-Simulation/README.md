# Phase 8: Docker & EC2 Simulation

## What You'll Learn

How Elastic Compute Cloud (EC2) virtual machines are emulated locally using Docker containers, how to manage Linux shells, port mappings, and volume mounts, configure SSH key credentials, and run application servers like Node.js and Nginx inside containers to mirror production deployments.

## Learning Objectives

- Explain the conceptual overlap and runtime differences between virtual machines (EC2) and containers (Docker).
- Deploy and configure Ubuntu-based containers to simulate EC2 instances.
- Implement secure SSH connections to running containers using public/private key pairs.
- Install and configure Nginx web servers and PM2 process managers inside containers.
- Route and forward ports to access containerized services from the host browser.
