# Phase 5: AWS Lambda

## What You'll Learn

How AWS Lambda works as a serverless compute engine, the execution lifecycle, and how to write Node.js handlers, zip function code, configure runtime environments, memory, and timeouts, and trigger execution dynamically on local emulators.

## Learning Objectives

- Explain the serverless event-driven execution model and function lifecycle.
- Write Lambda functions using Node.js handlers with events and context.
- Package and deploy Lambda functions locally using the AWS CLI.
- Run, test, and debug function execution triggers locally via Docker and Floci.
- Incorporate Lambda Layers to share shared code and node dependencies across functions.
