# Phase 10: Containers: ECS & ECR

## What You'll Learn

How Docker containers are managed and orchestrated in AWS using Elastic Container Registry (ECR) and Elastic Container Service (ECS), and how to build images, push them to a simulated local registry, define task configurations, and execute tasks locally.

## Learning Objectives

- Explain the roles of ECR (image registry) and ECS (container orchestration) in microservice architectures.
- Deploy a local Docker registry container to emulate ECR functionalities.
- Package and push Docker images to the local registry endpoint.
- Define ECS Task Definitions and Clusters using JSON schema templates.
- Launch and monitor ECS Tasks and Services locally using the AWS CLI and Docker.
