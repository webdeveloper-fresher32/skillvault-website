# Phase 4: DynamoDB Database

## What You'll Learn

How DynamoDB works as a managed NoSQL database service, the principles of single-table design, and how to create local tables, design partition keys (PK) and sort keys (SK), configure Global Secondary Indexes (GSIs), write Node.js SDK scripts to execute Queries and Scans, and manage TTL properties offline.

## Learning Objectives

- Explain the difference between relational databases and NoSQL key-value/document databases.
- Design DynamoDB tables using effective Partition Keys (PK) and Sort Keys (SK).
- Create tables and indexes locally using the AWS CLI and verify their schemas.
- Implement read/write CRUD operations, Query queries, and scan search patterns in Node.js.
- Configure and test Time to Live (TTL) parameters on local database records.
