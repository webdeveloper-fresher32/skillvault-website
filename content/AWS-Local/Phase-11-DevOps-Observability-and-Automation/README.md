# Phase 11: DevOps, Observability & Automation

## What You'll Learn

How local observability and DevOps frameworks are configured using CloudWatch Logs, metrics, and event schedulers, and how to build, test, and invoke serverless applications locally using the AWS SAM CLI framework.

## Learning Objectives

- Explain the importance of log consolidation and metrics monitoring in CloudWatch.
- Stream and query application logs locally inside CloudWatch Log Groups.
- Install and configure the AWS SAM (Serverless Application Model) CLI tool.
- Initialize, build, and run Lambda functions locally using `sam local invoke`.
- Configure EventBridge (CloudWatch Events) cron rules to schedule local Lambda jobs.
