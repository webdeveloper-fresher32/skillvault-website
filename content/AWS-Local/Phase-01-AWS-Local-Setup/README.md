# Phase 1: AWS Local Setup

## What You'll Learn

How local cloud emulation works, the architectural differences between running AWS in production vs. locally, and how to configure a fully functional local AWS environment on your computer using Floci, Docker, and the AWS CLI.

## Learning Objectives

- Explain the mechanics of local cloud emulation and the role of API endpoint overriding.
- Install and configure Docker and the AWS CLI on your system.
- Deploy and start the Floci container to emulate AWS services locally.
- Configure local CLI profiles with dummy credentials and execute standard AWS CLI commands directed at the local container.
