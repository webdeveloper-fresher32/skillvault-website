# Phase 7: SQS & SNS Messaging

## What You'll Learn

How SQS and SNS enable decoupling in distributed microservices, message queueing concepts, dead-letter queues (DLQ), message fan-out patterns, and how to create local SQS queues and SNS topics, publish events, and process messages offline.

## Learning Objectives

- Explain the difference between pub-sub (SNS) and message queueing (SQS).
- Create local queues, topics, and subscription links using the AWS CLI.
- Configure Dead-Letter Queues (DLQ) to capture failed messages locally.
- Implement a message publisher and subscriber application in Node.js.
- Demonstrate the "fan-out" architectural pattern, where one SNS event distributes to multiple SQS queues.
