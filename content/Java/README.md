# Java Programming & JVM Architecture

> "Java is an object-oriented, class-based, concurrent programming language designed for enterprise resilience, high concurrency, and long-term platform stability through the Java Virtual Machine (JVM)."

---

## 12-Phase Curriculum Overview

| Phase | Module | Key Topics |
|---|---|---|
| 01 | [Java Fundamentals & Setup](Phase-01-Java-Fundamentals-and-Setup/01-JDK-JRE-JVM-and-Your-First-Program.md) | JDK installation, bytecode compilation, primitives, flow control |
| 02 | [Object-Oriented Programming](Phase-02-Object-Oriented-Programming/01-Classes-Objects-and-Constructors.md) | Classes, inheritance, polymorphism, encapsulation, abstract classes, interfaces |
| 03 | [Arrays, Strings & Core Utilities](Phase-03-Arrays-Strings-and-Core-Utility-Classes/01-Arrays.md) | Immutable strings, StringPool, StringBuilder, Math, Date/Time API |
| 04 | [Collections Framework](Phase-04-Collections-Framework/01-Lists.md) | List, Set, Map, Queue, ArrayList vs LinkedList, HashMap internals |
| 05 | [Generics & Exception Handling](Phase-05-Generics-and-Exception-Handling/01-Generics.md) | Type erasure, bounded wildcards (`<? extends T>`), checked vs unchecked exceptions |
| 06 | [Lambdas & Streams](Phase-06-Lambdas-and-Streams/01-Functional-Interfaces-and-Lambda-Expressions.md) | Functional interfaces, lambda expressions, method references, stream pipelines |
| 07 | [Java I/O and NIO](Phase-07-Java-IO-and-NIO/01-Classic-IO-Streams-and-Readers.md) | Byte vs Character streams, Buffering, NIO Channels, Buffers, Selectors |
| 08 | [Concurrency & Multithreading](Phase-08-Concurrency-and-Multithreading/01-Threads-and-Race-Conditions.md) | Thread lifecycle, synchronization, locks, volatile, ThreadPoolExecutor, CompletableFuture |
| 09 | [JVM Internals & Memory](Phase-09-JVM-Internals-and-Memory-Management/01-Heap-Stack-and-the-Object-Lifecycle.md) | ClassLoader, JVM memory zones (Heap, Metaspace, Stack), Garbage Collection algorithms |
| 10 | [Modern Java Features](Phase-10-Modern-Java-Features/01-var-Records-and-Sealed-Classes.md) | Records, sealed classes, pattern matching, Virtual Threads (Project Loom) |
| 11 | [Build Tools & Testing](Phase-11-Build-Tools-and-Testing/01-Maven-and-Gradle-Fundamentals.md) | Maven, Gradle dependency graphs, JUnit 5, Mockito unit test suites |
| 12 | [Best Practices & Production](Phase-12-Best-Practices-and-Production-Patterns/01-Design-Principles-and-Common-Pitfalls.md) | Effective Java principles, memory leak profiling, JVM tuning parameters |
