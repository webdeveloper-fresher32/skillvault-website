# Phase 9: Data Structures & Algorithms

## What You'll Learn

Writing correct, idiomatic JavaScript is only half the job — a professional developer also needs to reason about how their code performs as data grows. This phase builds the classic computer-science toolkit using plain JavaScript: no libraries, no frameworks, just arrays, objects, closures, and recursion. You'll learn to analyze algorithms with Big-O notation, implement the core linear and non-linear data structures (linked lists, stacks, queues, trees, graphs) from scratch, and apply the searching and sorting algorithms that appear in almost every technical interview. By the end of this phase you will be able to pick the right data structure for a problem, explain its time/space trade-offs, and implement it in JavaScript without reaching for a library.

## Learning Objectives

- Analyze the time and space complexity of an algorithm using Big-O notation
- Apply two-pointer and sliding-window patterns to solve array/string problems in optimal time
- Implement singly and doubly linked lists, stacks, and queues, and explain when each is the right tool
- Implement a binary tree and traverse it with BFS and DFS, both recursively and iteratively with an explicit stack
- Implement binary search tree insert/search/delete and understand its average vs worst-case complexity
- Represent a graph with an adjacency list and traverse it with BFS and DFS
- Explain how a hash map achieves O(1) average lookup, including how collisions are handled
- Implement bubble sort, merge sort, and quick sort, and compare their complexity and stability
- Implement binary search and its common variants (first/last occurrence, search in rotated array)
