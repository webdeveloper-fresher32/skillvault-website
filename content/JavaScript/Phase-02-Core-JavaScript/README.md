# Phase 2: Core JavaScript

## What You'll Learn

With the fundamentals in place, this phase moves into the two data structures you will use constantly in real JavaScript code: arrays and objects. You'll learn how to build, mutate, and iterate over arrays using both classic and functional methods, how to model structured data with objects, and how modern destructuring and spread/rest syntax let you extract and combine data without verbose boilerplate. By the end of this phase you will comfortably reshape and transform real-world data — the kind you get back from an API — using idiomatic modern JavaScript.

## Learning Objectives

- Create arrays and access/modify elements by index
- Use mutating array methods (`push`, `pop`, `shift`, `unshift`, `splice`) and understand which methods mutate vs return new arrays
- Use iteration methods (`map`, `filter`, `reduce`, `find`, `forEach`, `some`, `every`) to transform and query arrays without manual loops
- Explain the difference between a real array and an array-like object (e.g. `arguments`, a `NodeList`)
- Create objects with literals, access properties with dot and bracket notation, and add methods
- Use `Object.keys`, `Object.values`, `Object.entries`, and `Object.freeze`
- Use computed property names to build dynamic object keys
- Destructure arrays and objects, including defaults, renaming, and nested patterns
- Use the spread operator to copy/merge arrays and objects and to expand arguments into function calls
- Use rest parameters to collect a variable number of arguments, and default parameters to handle missing ones
