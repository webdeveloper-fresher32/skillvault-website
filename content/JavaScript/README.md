# JavaScript — Complete Learning Course

Master pure JavaScript from zero to backend production depth. This course covers everything from core language fundamentals through closures, asynchronous programming, object-oriented patterns, modern ES6+ features, browser APIs, data structures & algorithms, and Node.js backend development — giving you the skills to build and reason about JavaScript applications on both the client and the server.

This course does **not** cover frontend frameworks (React, Vue, Angular, Next.js) — it assumes you already have some working React experience and instead deepens your grasp of the language itself. TypeScript is also out of scope here; see the TypeScript Deep-Dive Cheat Sheet elsewhere in this repo for that.

---

## Course Structure

```
JavaScript/
├── Phase-01-Fundamentals/              → Variables, data types, operators, control flow, functions, scope, template literals
├── Phase-02-Core-JavaScript/           → Arrays, objects, string/array methods, destructuring, spread/rest, default params
├── Phase-03-Advanced-JavaScript/       → Execution context, hoisting, closures, this, HOFs, IIFE, ES6 modules
├── Phase-04-DOM-Manipulation/          → Selecting elements, events, forms, DOM traversal
├── Phase-05-Asynchronous-JavaScript/   → Callbacks, Promises, async/await, Fetch API, event loop
├── Phase-06-Object-Oriented-JavaScript/ → Constructors, classes, inheritance, prototypes
├── Phase-07-Modern-JavaScript-ES6/     → Optional chaining, nullish coalescing, Sets/Maps, generators/iterators
├── Phase-08-Browser-APIs/              → localStorage/sessionStorage, cookies, geolocation, clipboard, Web Workers
├── Phase-09-Data-Structures-Algorithms/ → Linked lists, stacks, queues, hash maps, trees, graphs, sorting/searching in JS
├── Phase-10-Backend-JavaScript/        → Node.js core, Express.js, REST APIs, JWT auth, MongoDB, SQL basics, env vars
├── Phase-11-Production-Deployment/     → Testing, debugging, logging, CI/CD, deployment, best practices
├── Quick-Reference/                    → Cheatsheet + 50 interview Q&A
└── Projects/                           → Beginner → Advanced hands-on projects
```

## Prerequisites

- Basic command-line familiarity (navigating folders, running scripts)
- A code editor (e.g. VS Code)
- Node.js installed on your machine
- No prior JavaScript experience required — Phase 1 starts from scratch

## Quick Commands

```bash
node script.js                   # run a JavaScript file with Node.js
node --watch script.js           # auto-restart on file changes
npm init -y                      # initialize a new Node project
npm install express              # install a dependency
npm test                         # run the test suite
node --inspect script.js         # start Node.js with the debugger attached
```
