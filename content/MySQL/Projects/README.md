## How to Approach

1. Read the requirements carefully
2. Draw an ER diagram on paper before writing SQL
3. Normalize to 3NF first, then optimize
4. Write DDL (CREATE TABLE with all constraints)
5. Seed with realistic sample data
6. Write all the queries listed in requirements
7. Add appropriate indexes and run EXPLAIN
8. Implement any triggers or procedures required
