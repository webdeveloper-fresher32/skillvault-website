# Phase 09: Cloud Native Architecture

Taking a 15-year-old monolithic application and running it on an AWS EC2 instance means your app is *in* the cloud, but it is not *Cloud Native*. 

Cloud Native architecture is an approach to building and running applications that fully exploit the advantages of the cloud computing delivery model (elasticity, on-demand provisioning, resiliency).

## Learning Objectives

By the end of this phase, you will understand:
- The difference between Cloud-Ready and Cloud-Native.
- The 12-Factor App methodology (the gold standard for building modern SaaS apps).
- The role of Containerization (Docker) and Orchestration (Kubernetes) in Cloud Native design.
