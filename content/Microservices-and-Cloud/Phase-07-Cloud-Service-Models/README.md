# Phase 07: Cloud Service Models

Cloud computing is not a single product. It is a spectrum of services that dictate exactly how much responsibility you manage versus how much the cloud provider manages.

These are known as the Cloud Service Models: IaaS, PaaS, SaaS, and the modern addition, FaaS.

## Learning Objectives

By the end of this phase, you will understand:
- The "Pizza as a Service" analogy for cloud models.
- When to choose Infrastructure as a Service (IaaS) for maximum control.
- When to choose Platform as a Service (PaaS) for developer speed.
- How Software as a Service (SaaS) solves end-user business problems.
- The revolutionary pricing and execution model of Serverless (FaaS).

## Files in this Phase

1. `01-IaaS-and-PaaS.md`: The developer-centric models (e.g., AWS EC2 vs. Heroku).
2. `02-SaaS.md`: The consumer-centric model (e.g., Salesforce, Google Workspace).
3. `03-Serverless-and-FaaS.md`: The event-driven, scale-to-zero model (e.g., AWS Lambda).
