# Phase 12 — Interview Process and Advanced

Phases 01-11 gave you every building block a system design interview draws on — request lifecycles, scaling, load balancing, databases, caching, queues, storage/auth, distributed-systems theory, and eleven full case studies. Knowing the material is necessary but not sufficient: interviewers aren't grading a trivia quiz, they're grading a **45-minute live performance** — how you structure ambiguity, how you narrate trade-offs, and how you react when they push back. This phase turns everything you've learned into a repeatable interview performance: a framework you run every single time, a full worked transcript showing that framework live (including the pushback questions that rattle unprepared candidates), and the extensions that separate a mid-level answer from a staff-level one.

This is the capstone phase of the HLD course. There's no new distributed-systems concept here — it's entirely about *execution*: sequencing what you already know under a clock, in front of another person, on a topic you don't get to pick.

## What This Phase Covers

- A repeatable six-step sequence for any "design X" prompt — clarify, estimate, architect, deep-dive, discuss trade-offs, mention operability — with each step mapped back to the phase that taught it, plus the classic failure modes (jumping to a solution, silence during estimation, refusing to commit to a trade-off).
- A full worked mock interview transcript, applying that framework live to a real prompt, with realistic interviewer follow-ups and pushback and strong sample answers to each.
- Staff-level extensions that a senior/staff interview loop layers on top of the standard framework: multi-region architecture, disaster recovery (RPO/RTO), and capacity planning at 10x the scale a mid-level candidate is usually asked about.

## Estimated Time

**2 days** — one day to internalize the framework and read the transcript closely, one day to run the framework yourself out loud against 2-3 case studies from Phases 10-11 before layering on the staff-level extensions.

## Prerequisites

All prior phases (01-11). This phase assumes you've already built the vocabulary and case-study repertoire — it's the layer that organizes that knowledge into something you can execute live, under time pressure, in front of an interviewer.
