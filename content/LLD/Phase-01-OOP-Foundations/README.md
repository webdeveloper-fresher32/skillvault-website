# Phase 01: Object-Oriented Foundations in Java

Object-Oriented Programming (OOP) in Java forms the structural bedrock of enterprise software engineering and Low-Level Design (LLD) interviews. This phase covers essential principles, JVM memory models, dynamic dispatch, robust constructors, encapsulation, composition, and modern Java records.

## 📚 Lessons in This Phase

1. **[01-Classes-Objects-and-Constructors.md](01-Classes-Objects-and-Constructors.md)**: Heap allocation, constructor chaining (`this()`), defensive copying of references.
2. **[02-Inheritance-and-Polymorphism.md](02-Inheritance-and-Polymorphism.md)**: Virtual methods, runtime dynamic dispatch, `super` initialization, and sealed classes.
3. **[03-Abstraction-and-Encapsulation.md](03-Abstraction-and-Encapsulation.md)**: Access modifiers, invariant protection, and the "Tell, Don't Ask" (TDA) principle.
4. **[04-Method-Overriding-and-Overloading.md](04-Method-Overriding-and-Overloading.md)**: Static binding vs dynamic dispatch, `@Override`, covariant return types, exception narrowing.
5. **[05-Composition-vs-Inheritance.md](05-Composition-vs-Inheritance.md)**: Fragile base class problem, forwarding/delegation wrappers, HAS-A vs IS-A.
6. **[06-Static-and-Class-Methods.md](06-Static-and-Class-Methods.md)**: Metaspace, static factory methods, utility class non-instantiability.
7. **[07-Magic-Methods-and-Properties.md](07-Magic-Methods-and-Properties.md)**: The `equals()` and `hashCode()` contract, `toString()`, and `Comparable<T>`.
8. **[08-Dataclasses.md](08-Dataclasses.md)**: Modern Java Records, compact constructors, immutable DTOs, and value objects.
