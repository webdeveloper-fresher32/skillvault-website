# Phase 03: UML & Object Modeling in Java

Visual modeling with the Unified Modeling Language (UML) bridges high-level requirements with production-ready Java code. This phase covers UML class diagrams, relationships (Dependency, Association, Aggregation, Composition, Inheritance, Realization), sequence diagrams, and the noun-extraction technique for machine coding interviews.

## 📚 Lessons in This Phase

1. **[01-Class-Diagrams-Basics.md](01-Class-Diagrams-Basics.md)**: Class anatomy, visibility modifiers, the 6 core UML relationships in Java, multiplicity, sequence diagrams, and an end-to-end ride booking case study.
2. **[02-Identifying-Objects-and-Responsibilities.md](02-Identifying-Objects-and-Responsibilities.md)**: Noun-extraction technique, Information Expert principle, worked examples for WhatsApp, Library Management, and Elevator System in Java.
3. **[03-Core-Design-Principles.md](03-Core-Design-Principles.md)**: DRY, KISS, YAGNI, Composition over Inheritance, Law of Demeter, and Separation of Concerns with Java refactoring.
