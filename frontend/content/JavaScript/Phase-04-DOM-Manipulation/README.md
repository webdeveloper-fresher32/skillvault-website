# Phase 4: DOM Manipulation

## What You'll Learn

This phase takes JavaScript out of the console and into the browser. You'll learn how to select elements from a live HTML page, read and change their content, styling, and attributes, respond to user interaction through events, and build and remove elements dynamically. This is the phase where the language starts feeling like the tool that powers every interactive website you've ever used — by the end you'll be able to build a fully interactive page (forms, buttons, dynamic lists) using nothing but vanilla JavaScript and the DOM APIs, with no framework required.

## Learning Objectives

- Select single and multiple elements using `querySelector`, `querySelectorAll`, `getElementById`, `getElementsByClassName`, and `getElementsByTagName`
- Read and modify element content using `textContent`, `innerHTML`, and `innerText`, and explain the security and performance differences between them
- Manipulate CSS classes with `classList` (`add`, `remove`, `toggle`, `contains`) and inline styles with the `style` property
- Read, set, and remove HTML attributes
- Attach event listeners with `addEventListener` and read data off the event object
- Explain event bubbling and capturing, and use event delegation to handle events on dynamically added elements efficiently
- Use `preventDefault()` and `stopPropagation()` correctly and explain the difference
- Traverse the DOM tree using `parentNode`, `children`, `nextElementSibling`, and `previousElementSibling`
- Create, insert, and remove DOM nodes programmatically with `createElement`, `appendChild`, `removeChild`, and `insertBefore`
- Read form input values and respond to form submission events correctly
