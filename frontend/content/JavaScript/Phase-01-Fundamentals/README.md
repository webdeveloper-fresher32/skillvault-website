# Phase 1: Fundamentals

## What You'll Learn

This phase is the on-ramp into JavaScript for someone starting from scratch. You will learn how JavaScript stores and labels data, how to make decisions and repeat work, and how to package logic into reusable functions. These are the building blocks every later phase depends on — before you can understand closures, the event loop, or React components, you need to be fluent in variables, control flow, loops, and functions. By the end of this phase you will be able to read and write small, correct JavaScript programs and explain exactly what every line does.

## Learning Objectives

- Declare variables with `var`, `let`, and `const`, and explain the scoping and re-assignment differences between them
- Identify all seven primitive types in JavaScript and use `typeof` to inspect them
- Predict the result of type coercion in common expressions (`"5" + 3`, `"5" - 3`, `[] + []`)
- Build strings with template literals instead of concatenation
- Use arithmetic, comparison, and logical operators correctly, including the critical `==` vs `===` distinction
- Write `if/else`, `switch`, and ternary expressions to branch program logic
- Write `for`, `while`, `do-while`, `for-of`, and `for-in` loops and choose the right one for a given data shape
- Define functions three ways — declarations, expressions, and arrow functions — and explain the practical differences
- Distinguish function scope from block scope and explain how parameters work
