## Key Concepts

- **Resource Management** - Setting CPU and memory limits to prevent container resource exhaustion
- **Logging Drivers** - Configuring how and where Docker routes container log output
- **Centralised Logging** - Aggregating logs from multiple containers into a single destination
- **Monitoring Stacks** - Using Prometheus and Grafana to collect and visualise container metrics
- **cAdvisor** - Container resource usage and performance monitoring
