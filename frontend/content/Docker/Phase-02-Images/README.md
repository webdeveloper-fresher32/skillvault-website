# Phase 2: Docker Images

## What You'll Learn

Images are the blueprint for containers. Master building, optimizing, and managing Docker images.

## Learning Objectives

- Understand image layers and the union filesystem
- Write effective Dockerfiles from scratch
- Understand build caching and how to leverage it
- Choose the right base images
- Tag and manage images
