# Phase 1: Docker Fundamentals

## What You'll Learn

Understand what Docker is, why it exists, and how it changes the way software is built and shipped. Get your environment set up and run your first containers.

## Learning Objectives

- Explain what Docker is and the problem it solves
- Understand the difference between containers and VMs
- Install Docker Desktop / Docker Engine
- Run, inspect, and stop your first containers
- Understand the Docker architecture (daemon, CLI, registry)
