# What is Cloud Computing?

Cloud computing is the delivery of computing services—including servers, storage, databases, networking, software, and analytics—over the Internet ("the cloud"). 

Instead of buying and maintaining physical data centers and servers, you rent access to these services from a cloud provider (like Amazon Web Services, Microsoft Azure, or Google Cloud) on an as-needed basis.

## The 5 Essential Characteristics (NIST Definition)

The National Institute of Standards and Technology (NIST) strictly defines cloud computing by five essential characteristics. If a system doesn't have all five, it is not a true cloud.

### 1. On-Demand Self-Service
A consumer can provision computing capabilities (like server time or network storage) automatically, without requiring human interaction with the service provider. You click a button in the AWS console, and an EC2 instance boots up instantly.

### 2. Broad Network Access
Capabilities are available over the network (usually the public Internet) and accessed through standard mechanisms that promote use by heterogeneous client platforms (mobile phones, tablets, laptops, and workstations).

### 3. Resource Pooling
The provider's computing resources are pooled to serve multiple consumers using a **multi-tenant model**, with different physical and virtual resources dynamically assigned and reassigned according to consumer demand. The customer generally has no control or knowledge over the exact physical location of the provided resources.

### 4. Rapid Elasticity
Capabilities can be elastically provisioned and released, in some cases automatically, to scale rapidly outward and inward commensurate with demand. To the consumer, the capabilities available for provisioning often appear to be unlimited. (e.g., Auto-scaling from 2 servers at midnight to 200 servers on Black Friday).

### 5. Measured Service (Pay-as-you-go)
Cloud systems automatically control and optimize resource use by leveraging a metering capability. Resource usage can be monitored, controlled, and reported, providing transparency for both the provider and consumer of the utilized service. You only pay for exactly what you use, often billed by the second.

## Summary
The cloud is not just "someone else's computer." It is a highly automated, elastic, multi-tenant environment where resources are pooled and metered by the second.
