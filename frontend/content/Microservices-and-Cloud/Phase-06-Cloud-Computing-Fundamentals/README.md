# Phase 06: Cloud Computing Fundamentals

Microservices are almost exclusively deployed in the cloud. To understand modern software architecture, you must understand the foundational concepts of Cloud Computing.

This phase shifts focus from application design to the underlying infrastructure that powers it.

## Learning Objectives

By the end of this phase, you will understand:
- The exact definition of Cloud Computing according to NIST.
- The fundamental technology that makes the cloud possible: Virtualization.
- The financial shift from Capital Expenditure (CAPEX) to Operational Expenditure (OPEX).

## Files in this Phase

1. `01-What-is-Cloud-Computing.md`: Core definitions and the 5 essential characteristics of the cloud.
2. `02-Virtualization-and-Hypervisors.md`: How one physical server acts like a hundred servers.
3. `03-CAPEX-vs-OPEX.md`: The economic argument for the cloud.
