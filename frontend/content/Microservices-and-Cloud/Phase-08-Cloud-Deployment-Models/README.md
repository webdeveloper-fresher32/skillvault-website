# Phase 08: Cloud Deployment Models

While Service Models (IaaS, PaaS, SaaS) dictate *how much* you manage, Deployment Models dictate *where* the infrastructure physically lives and *who* has access to it.

Understanding deployment models is critical for system design interviews, especially when dealing with compliance, data sovereignty, and disaster recovery.

## Learning Objectives

By the end of this phase, you will understand:
- The fundamental differences between Public and Private clouds.
- Why organizations adopt Hybrid Cloud architectures.
- The complexities and trade-offs of a Multi-Cloud strategy.

## Files in this Phase

1. `01-Public-and-Private-Cloud.md`: The two extremes of cloud deployment.
2. `02-Hybrid-Cloud.md`: Combining on-premises security with public cloud elasticity.
3. `03-Multi-Cloud-Architecture.md`: Using multiple public cloud providers simultaneously to avoid vendor lock-in.
