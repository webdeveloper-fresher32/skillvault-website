# Phase 14: Advanced AWS

This phase covers advanced AWS services and concepts for professionals building enterprise-grade, secure, cost-optimized, and data-driven architectures. These topics appear in the Solutions Architect Professional and Specialty certification exams and are regularly asked in senior cloud engineering interviews.

## Modules

| File | Topic | What You'll Learn |
|------|-------|-------------------|
| `01-Advanced-Security.md` | Advanced Security Services | GuardDuty, WAF, Shield, Macie, Inspector, Security Hub, Firewall Manager, IAM Analyzer, ACM, Secrets Manager |
| `02-Data-Analytics.md` | Data & Analytics Services | Redshift, Athena, Glue, Kinesis, EMR, OpenSearch, QuickSight, Lake Formation |
| `03-Advanced-Networking.md` | Advanced Networking | Transit Gateway, PrivateLink, Direct Connect, VPN, Global Accelerator, Network Firewall |
| `04-Cost-Optimization.md` | Cost Optimization | Pricing models, cost tools, FinOps practices, right-sizing |

## Learning Objectives

By the end of this phase you will be able to:

- Design a comprehensive AWS security posture using detective and preventive controls
- Build data pipelines from real-time ingestion through analytics and visualization
- Design hybrid and multi-VPC network architectures at enterprise scale
- Identify and eliminate cloud waste, select appropriate pricing models, and implement FinOps practices
- Answer advanced-level interview questions on these topics with confidence

## Who This Is For

- Cloud engineers working toward Solutions Architect Professional certification
- DevOps engineers needing deeper AWS platform knowledge
- Data engineers building analytics platforms on AWS
- Security engineers designing defense-in-depth strategies
- Technical leads responsible for cloud cost governance

## Prerequisites

- Phases 1–13 completed
- Strong understanding of: VPCs, IAM, EC2, RDS, S3, Lambda, ECS, CloudFormation
- Comfortable reading and writing AWS architecture diagrams
