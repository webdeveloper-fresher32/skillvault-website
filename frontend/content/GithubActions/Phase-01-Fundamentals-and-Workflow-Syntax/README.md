# Phase 1: Fundamentals and Workflow Syntax

## What You'll Learn

Get comfortable with the YAML syntax GitHub Actions workflows are written in, understand the anatomy of a workflow file, and learn the step model that every job is built from.

## Learning Objectives

- Read and write valid workflow YAML
- Explain a workflow file's top-level anatomy
- Distinguish `uses` steps from `run` steps and know when shell state persists across steps
