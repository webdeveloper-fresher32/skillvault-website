# Phase 4: Transformers

> **Pillar 4 of 7: Transformers & LLMs** — Attention, Embeddings, BERT/GPT, Architectures

## What You'll Learn

The complete Transformer architecture from first principles: sub-word tokenization algorithms, embedding vector spaces, positional encodings, Scaled Dot-Product Self-Attention ($Q, K, V$), Multi-Head Attention, residual connections, layer normalization, and the fundamental differences between BERT, GPT, and T5.

## Learning Objectives

- Understand tokenization algorithms (Byte-Pair Encoding, WordPiece) and how tokens map to dense embedding vectors and positional coordinates (Sinusoidal and RoPE).
- Derive and implement Scaled Dot-Product Self-Attention and Multi-Head Attention from scratch, understanding how tokens route information dynamically.
- Distinguish Encoder-Only (BERT), Decoder-Only (GPT), and Encoder-Decoder (T5) model paradigms, understanding why modern generative LLMs are causal decoders.
