# Phase 7: AI Agents

> **Pillar 6 of 7: AI Agents** — LangGraph, Tool-Calling, Multi-Agent Orchestration

## What You'll Learn

How to build autonomous agentic systems that extend beyond single prompt-response interactions: the ReAct (Reasoning + Acting) loop, tool calling execution pipelines, working vs long-term persistent memory, planning strategies, human-in-the-loop governance, and multi-agent coordination architectures.

## Learning Objectives

- Master the evolutionary arc: Prompt $\rightarrow$ Tool Calling $\rightarrow$ RAG $\rightarrow$ Memory $\rightarrow$ Planning $\rightarrow$ Autonomous Agent.
- Implement the ReAct loop from first principles with cycle detection, recursion limits, and error handling.
- Build multi-agent workflows (Supervisor/Router networks, peer-to-peer swarms, and handoffs), and understand state persistence across sessions.
