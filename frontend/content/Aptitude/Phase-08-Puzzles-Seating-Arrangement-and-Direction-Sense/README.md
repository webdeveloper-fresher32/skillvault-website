# Phase 8: Puzzles, Seating Arrangement, and Direction Sense

## What You'll Learn

This phase builds directly on the diagramming instinct from Phase 7 and applies it to a bigger family of puzzles: figuring out exactly who sits where, who lives on which floor, and who belongs to which group — all from a handful of scattered clues that only add up to one answer when combined in the right order. Start with linear and circular seating arrangement — setting up a slot diagram or elimination grid, handling rows where everyone faces the same direction (or doesn't), and getting comfortable with the left/right reversal that happens at a circular table depending on whether people face the centre or face outward. Finish with puzzles, grouping, and scheduling — the same elimination-table method applied to floor/box puzzles, day-of-week and month scheduling, and multi-attribute grouping puzzles. (Direction sense itself — walking a path of turns and finding net displacement — was already covered in Phase 7's [Blood Relations and Direction Sense](../Phase-07-Series-Coding-Decoding-and-Blood-Relations/03-Blood-Relations-and-Direction-Sense.md) lesson and isn't repeated here.)

## Learning Objectives

- Build and fill an elimination grid for seating puzzles — anchoring absolute clues first, chaining immediate-neighbor clues off them, then using counting/"somewhere" clues to close out the last few seats
- Distinguish linear arrangement rules (same-direction rows vs. one person facing the opposite way) from circular/rectangular arrangement rules (facing the centre vs. facing outward, and how that flips left/right)
- Solve scheduling and grouping puzzles with the same elimination-table method used for seating — floors, days, months, and multi-attribute groups all reduce to the same fix-then-chain-then-count process
