# Phase 10: Data Sufficiency and Non-Verbal Reasoning

## What You'll Learn

This is the final Logical Reasoning phase (Phases 7–10), closing out the sequence that started with series and coding-decoding and moved through puzzles and syllogisms. Data sufficiency asks a different kind of discipline than anything so far: instead of solving a problem, you judge whether given information is *enough* to solve it — evaluating each of two statements in strict isolation before ever combining them, resisting the constant temptation to let a fact from one statement leak into your reading of the other. Non-verbal reasoning shifts the medium entirely, from words and numbers to figures — rotation series, mirror images, odd-one-out classification, and embedded figures — all described here in text and ASCII form since this is a text-based course. Together, these close out Logical Reasoning; Phases 11–12 move into Verbal Ability.

## Learning Objectives

- Apply the standard five-option data-sufficiency discipline (statement I alone / statement II alone / either alone / both together / neither) by evaluating each statement in complete isolation first, without letting information from one statement leak into the evaluation of the other, and only combining them as a last resort
- Recognize the "either" trap where each statement alone is independently sufficient even if the values they produce differ, since sufficiency is judged per statement rather than by cross-checking the statements against each other
- Solve non-verbal reasoning problems — rotation series, mirror-image identification, shape addition/counting, figure classification, and embedded figures — by isolating the one governing rule or structural property from a precise text/ASCII description of each figure
