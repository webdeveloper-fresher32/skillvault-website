# Phase 2: Percentages, Profit & Loss, and Averages

## What You'll Learn

Turn percentage conversions and successive changes into instant mental math, then apply that same machinery to profit/loss/discount chains and to averages, average speed, and mixture (alligation) problems.

## Learning Objectives

- Convert between percentages and fractions instantly, and correctly combine successive percentage changes
- Solve profit-and-loss problems including marked price, successive discounts, and false-weight scenarios
- Apply alligation for mixture problems and compute weighted and average-speed values correctly
