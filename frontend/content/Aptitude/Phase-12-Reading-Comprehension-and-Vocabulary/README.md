# Phase 12: Reading Comprehension and Vocabulary

## What You'll Learn

This is the final phase of the course, and it completes the Verbal Ability pair (Phases 11–12) that followed the six Quantitative phases (1–6) and four Logical Reasoning phases (7–10). Reading comprehension and vocabulary questions test something different from grammar rules: instead of spotting a single flawed word or phrase, you must extract meaning from an entire passage — or from a single unfamiliar word — under the same tight time pressure. This phase teaches a time-boxed skim-first strategy for tackling RC passages instead of reading every word carefully, a classification system for the four recurring RC question types, and a root-word technique for handling vocabulary you have never seen before.

## Learning Objectives

- Apply a time-boxed reading comprehension strategy — skimming first for overall shape, then hunting selectively for each answer — instead of reading the full passage carefully end to end
- Classify RC questions into main idea, inference, detail, and tone/attitude types, and use each type to decide where and how to search the passage
- Use the root-word technique to break down unfamiliar vocabulary into recognizable prefixes, roots, and suffixes, and apply it to synonym, antonym, and idiom questions under time pressure
