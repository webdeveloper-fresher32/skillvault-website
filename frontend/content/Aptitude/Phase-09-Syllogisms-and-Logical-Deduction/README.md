# Phase 9: Syllogisms and Logical Deduction

## What You'll Learn

This phase moves from spatial/relational puzzles (Phase 8) into pure verbal-logic questions, where the only tool you're allowed to use is what the given statements actually force — never outside knowledge or gut feeling. Start with syllogisms, learning to solve "All/No/Some/Some...not" statement pairs by drawing every Venn diagram consistent with the premises (not just the first one that comes to mind) and checking whether a proposed conclusion survives every one of them, including the classic complementary-pair "either/or" case. Finish with statement-based reasoning — telling a necessary conclusion apart from an unstated assumption using the negation test, judging whether an argument is strong or weak, and picking a sensible, proportionate course of action over an extreme one.

## Learning Objectives

- Solve two-statement syllogisms by drawing all Venn diagrams consistent with the premises — instead of relying on memorized syllogism-form rules — and testing each proposed conclusion against every valid diagram
- Recognize when neither offered conclusion follows individually but together they form a genuine complementary pair (A/O or I/E on the same terms), forcing an "either...or" answer
- Separate a necessary conclusion (a fact the statement directly forces) from an implicit assumption (an unstated belief the statement depends on) using the negation test, and evaluate strong/weak arguments and course-of-action questions with the same "does it actually address the specific issue" discipline
