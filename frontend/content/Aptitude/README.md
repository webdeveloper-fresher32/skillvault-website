# Aptitude — Complete Learning Course

Master the first-round aptitude exam used in campus and off-campus tech hiring. This course covers Quantitative Aptitude, Logical Reasoning, and Verbal Ability — the same general-purpose mix asked across service-based company drives (TCS, Infosys, Wipro, Cognizant, etc.) and the aptitude/OA rounds product-style companies run before their coding rounds.

Most tech hiring pipelines — service-based and product-style alike — open with a written aptitude test before any coding round. That test draws from three areas: **Quantitative Aptitude** (number systems, percentages, ratios, time-speed-distance, interest, geometry, permutations & combinations), **Logical Reasoning** (series, coding-decoding, puzzles, syllogisms, data sufficiency), and **Verbal Ability** (grammar, sentence correction, reading comprehension, vocabulary). This course builds all three from first principles, in exam-speed style, through 12 phases, five full-length mock tests, and a quick-reference cheatsheet + interview Q&A set.

## Prerequisites

- Comfort with school-level arithmetic (fractions, percentages, basic algebra) — this course re-teaches the exam-speed shortcuts, not the underlying math from scratch.
- Working knowledge of English grammar at a high-school level — Phase 11-12 sharpen and formalize this, they don't start from zero.
- No prior aptitude-test experience assumed. This course is written for first-time test-takers as much as for those revising before an upcoming drive.
