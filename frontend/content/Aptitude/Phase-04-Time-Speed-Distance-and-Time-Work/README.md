# Phase 4: Time-Speed-Distance and Time-Work

## What You'll Learn

Build fluency with speed, distance, and time so unit conversions and relative-speed setups become automatic rather than something you re-derive under time pressure. Extend that same relative-speed thinking to trains (crossing poles, platforms, and other trains) and to boats and streams (upstream/downstream speed). Then pivot to time-and-work, where the same rate-based reasoning — expressed as "work per day" instead of "distance per hour" — lets you combine workers, wages, and pipes/cisterns with one consistent technique.

## Learning Objectives

- Convert units (km/h ↔ m/s) and apply relative speed instantly for bodies moving toward, away from, or alongside each other
- Solve train-crossing problems (pole, platform, another train) and boat/stream problems using combined length and combined/opposed speed
- Convert work problems into a rate-per-day, combine rates for multiple workers or pipes, and apply the correct sign convention for pipes and cisterns
