# Phase 1: Fundamentals

## What You'll Learn

Understand what a shell is, how Bash works, and write your first executable script.

## Learning Objectives

- Explain the difference between shell, terminal, and bash
- Create and run a shell script
- Understand the shebang line and execute permissions
- Use basic built-in commands
