# Shell Scripting — Complete Learning Course

Master Bash shell scripting from zero to automation-ready. This course builds the scripting foundation you need to work confidently with AWS CLI, EC2 automation, S3 operations, and infrastructure scripting.

---

## Course Structure

```
ShellScripting/
├── Phase-01-Fundamentals/        → What is shell, bash basics, first script
├── Phase-02-Variables/           → Variables, data types, special variables
├── Phase-03-Control-Flow/        → if/else, test conditions, case statements
├── Phase-04-Loops/               → for, while, until, break/continue
├── Phase-05-Functions/           → Defining, calling, returning values
├── Phase-06-Input-Output/        → Redirection, pipes, stdin/stdout/stderr
├── Phase-07-File-Operations/     → File tests, read/write, directory ops
├── Phase-08-Text-Processing/     → grep, sed, awk — parse real-world output
├── Phase-09-Script-Arguments/    → $@, getopts, flags, validation
├── Phase-10-Error-Handling/      → set -e, traps, debugging, exit codes
├── Phase-11-Automation/          → cron, at, systemd timers
├── Phase-12-AWS-Scripting/       → AWS CLI in scripts, jq, real patterns
├── Quick-Reference/              → Cheatsheet + 40 Interview Q&A
└── Projects/                     → Beginner → Advanced hands-on projects
```

## Why Shell Scripting Before AWS?

AWS CLI outputs JSON/text that you parse with `grep`, `awk`, and `jq`. Automation scripts use loops to iterate over EC2 instances, S3 buckets, and IAM roles. Error handling keeps production scripts safe. Learning shell first means AWS scripting feels natural, not painful.
