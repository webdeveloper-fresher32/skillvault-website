# Phase 1: Fundamentals and Setup

## What You'll Learn

Understand what Next.js adds on top of plain React, get comfortable navigating the App Router's file-based project structure, and build the Server/Client Component mental model that underpins everything else in this course.

## Learning Objectives

- Explain what Next.js adds over plain React and why teams choose it over a client-only setup
- Navigate the `app/` directory convention and map folder structure to URL routes
- Describe the Server Component vs. Client Component mental model and when `"use client"` is required
