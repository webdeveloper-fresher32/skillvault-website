# Phase 12: Deployment and Production

In this final phase of the course, we cover how to take your Next.js application from a local development environment to a production server where it can be accessed by users worldwide.

Next.js offers incredible flexibility. It can be deployed with zero configuration to Vercel (the creators of Next.js), exported as a static site, or self-hosted on any server that supports Node.js or Docker.

## Learning Objectives

By the end of this phase, you will understand:
- How to deploy a Next.js application seamlessly to Vercel.
- How to self-host Next.js using Node.js servers, Docker, and Nginx.
- How to configure CI/CD pipelines (e.g., GitHub Actions) for automated testing and deployment.
- Production best practices including environment variables, monitoring, and telemetry.

## Files in this Phase

1. `01-Vercel-Deployment.md`: The easiest and most optimized way to deploy Next.js.
2. `02-Self-Hosting-Nextjs.md`: Deploying to VPS, AWS EC2, or using Docker containers.
3. `03-CI-CD-and-Monitoring.md`: Automating deployments and monitoring production health.
