# Career Learning Paths

> "Domains organize knowledge into logical technical topics; career paths sequence that knowledge into an actionable, progressive learning order tailored to specific engineering roles."

## Select Your Engineering Path

| Career Path | Primary Focus | Recommended Starting Point | Roadmap Guide |
|---|---|---|---|
| **Full-Stack Engineer** | End-to-end web applications, reactive user interfaces, backend APIs, relational databases, and cloud deployment. | Foundations $\to$ JavaScript/React $\to$ Node/Spring $\to$ PostgreSQL | [Full-Stack Roadmap](01-Full-Stack-Engineer.md) |
| **Backend Engineer** | High-throughput distributed systems, concurrent request processing, ACID/BASE data storage, and microservices architecture. | Foundations $\to$ DSA $\to$ Java/Node $\to$ SQL/NoSQL $\to$ HLD | [Backend Roadmap](02-Backend-Engineer.md) |
| **AI Engineer** | Foundation models, vector similarity search, enterprise RAG pipelines, autonomous agent state machines, and model evaluation. | Math Foundations $\to$ Deep Learning $\to$ Transformers $\to$ RAG $\to$ LangGraph | [AI Engineer Roadmap](03-AI-Engineer.md) |
| **Cloud & DevOps Engineer**| Infrastructure as Code, continuous integration/continuous deployment pipelines, container orchestration, and site reliability. | Linux/Shell $\to$ Networking $\to$ Docker $\to$ Terraform $\to$ Kubernetes | [Cloud & DevOps Roadmap](04-Cloud-DevOps-Engineer.md) |

## How to Use These Roadmaps

1. **Follow the Sequence**: Each career path orders learning phases from core primitives to advanced production concerns.
2. **Consult the Domain Hubs**: The links within each roadmap take you directly into deep-dive course modules across `01-FOUNDATIONS/`, `02-SOFTWARE-ENGINEERING/`, `03-APPLICATION-DEVELOPMENT/`, `04-SYSTEMS-INFRASTRUCTURE/`, and `05-AI/`.
3. **Build the Associated Projects**: Practical mastery requires building. Follow the tiered project recommendations in [06-PROJECTS/](../06-PROJECTS/README.md) as you complete each phase.
4. **Prepare for Interviews**: Finish with role-specific interview preparation and behavioral question strategies in [07-INTERVIEW-PREP/](../07-INTERVIEW-PREP/README.md).
