# Phase 2: Angular CLI & Workspace

## What You'll Learn

Get hands-on with the Angular CLI — the tool you'll use to scaffold, serve, and build every Angular app you write — and learn how a generated workspace is organized so you can navigate any Angular codebase with confidence.

## Learning Objectives

- Install the Angular CLI and verify the setup with `ng version`
- Scaffold a new workspace with `ng new` and understand its prompts
- Serve an application locally for development with `ng serve`
- Identify the purpose of key config files: `angular.json`, `package.json`, `tsconfig.json`
- Navigate the `src/app/` structure, including `app.config.ts` and `app.routes.ts` in modern Angular
