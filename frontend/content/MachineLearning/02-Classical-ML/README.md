# Phase 2: Classical Machine Learning

> **Pillar 2 of 7: Classical ML** — scikit-learn, Regression/Classification, Clustering

## What You'll Learn

The mental models, algorithms, evaluation metrics, and validation disciplines of classical machine learning — moving from hand-coded rules to learning functions $f(x)=y$ from tabular data using scikit-learn, XGBoost, and statistical validation.

## Learning Objectives

- Master supervised learning algorithms: Linear Regression, Logistic Regression, Decision Trees, Random Forests, Gradient Boosted Trees (XGBoost), SVMs, and KNN.
- Implement unsupervised clustering (K-Means) and dimensionality reduction (PCA) for discovering hidden structures in unlabeled datasets.
- Master the bias-variance tradeoff, cross-validation splits, feature engineering, classification metrics (Precision, Recall, F1, ROC-AUC), regression metrics (MAE, MSE, RMSE, R²), and data leakage prevention.
