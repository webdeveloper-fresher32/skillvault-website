# Phase 07: Java Features & Concurrency for LLD

Low-Level Design in Java demands a firm grasp of language mechanisms that enforce clean contracts, immutability, type safety, and robust multi-threading. This phase covers the foundational Java building blocks required to master whiteboard and machine coding interviews.

## 📚 Lessons in This Phase

1. **[01-Interfaces-and-Abstract-Classes.md](01-Interfaces-and-Abstract-Classes.md)**: "Can-Do" vs "Is-A", default methods, static methods, functional interfaces.
2. **[02-Generics-and-Type-Safety.md](02-Generics-and-Type-Safety.md)**: Generic classes, bounded types, type erasure, and the PECS principle (`? extends` / `? super`).
3. **[03-Enums-Records-and-Immutability.md](03-Enums-Records-and-Immutability.md)**: Rich enums with state machines, Strategy pattern inside enums, Java 14+ records, compact constructors.
4. **[04-Java-Collections-and-Stream-API.md](04-Java-Collections-and-Stream-API.md)**: Collections selection matrix, PriorityQueue, ConcurrentHashMap, Stream API filtering and aggregation.
5. **[05-AutoCloseable-and-Resource-Management.md](05-AutoCloseable-and-Resource-Management.md)**: RAII pattern in Java, try-with-resources, safe auto-closing lock scopes, connection lease management.
6. **[06-Dependency-Injection-and-IoC.md](06-Dependency-Injection-and-IoC.md)**: Inversion of control, constructor injection, lightweight pure Java IoC container from scratch.
7. **[07-Concurrency-and-Thread-Safety-in-Java.md](07-Concurrency-and-Thread-Safety-in-Java.md)**: Thread lifecycle, JMM, race conditions, volatile, synchronized, ReentrantLock, ReadWriteLock, Atomic CAS, deadlock prevention.
