# Phase 12: AI & Cloud Simulation

## What You'll Learn

How to conceptually align and simulate expensive AWS AI services locally without a cloud connection. You will learn to mock SageMaker model registries and training containers using local FastAPI servers, Docker, and MLflow, and swap Bedrock Foundation Models offline using Ollama and the LangChain framework.

## Learning Objectives

- Explain the API parameters and pipelines of Amazon SageMaker and Bedrock.
- Simulate SageMaker Jupyter notebooks and training jobs using local VS Code and Docker.
- Build local model serving endpoints using Python, FastAPI, and Docker.
- Run local Large Language Models (LLMs) offline using Ollama.
- Write LangChain code that uses local Ollama models, keeping code structure compatible with a future migration to Amazon Bedrock.
