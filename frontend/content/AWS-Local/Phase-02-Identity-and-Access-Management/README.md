# Phase 2: Identity & Access Management

## What You'll Learn

How AWS Identity and Access Management (IAM) behaves under local emulation, how policies are structured and evaluated in theory, and how to define local users, groups, roles, and policies using the AWS CLI and custom credentials.

## Learning Objectives

- Understand the core pillars of IAM: Users, Groups, Roles, Policies, and Access Keys.
- Explain the key differences between live AWS IAM enforcement and local IAM emulation.
- Create local mock users, groups, and policies using the AWS CLI directed at the Floci container.
- Configure and test local cross-account IAM role assumption scenarios offline.
