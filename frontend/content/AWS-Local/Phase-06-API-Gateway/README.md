# Phase 6: API Gateway

## What You'll Learn

How Amazon API Gateway acts as an entry point for HTTP clients, the differences between REST APIs and HTTP APIs, and how to create routes, integrate them with local Lambda functions, configure CORS headers, and deploy stages offline.

## Learning Objectives

- Explain API Gateway routing models, HTTP proxy integrations, and authorizers.
- Build REST and HTTP APIs locally using the AWS CLI.
- Link API Gateway endpoints directly to local AWS Lambda functions.
- Configure CORS mapping to allow cross-origin requests from web frontends (like React).
- Invoke and test local endpoint routes using `curl` and inspect response payloads.
