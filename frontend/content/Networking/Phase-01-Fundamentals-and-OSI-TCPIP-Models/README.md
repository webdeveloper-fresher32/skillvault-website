# Phase 01 — Fundamentals and OSI/TCP-IP Models

## Overview

This phase builds the mental model every networking topic afterward depends on. You'll learn why networks exist, how the industry standardized communication into layers (OSI), how the real-world internet actually implements those layers (TCP/IP), and how a single HTTP request is wrapped and unwrapped in headers as it physically travels from your browser to a server and back.

By the end of this phase you should be able to whiteboard the OSI model from memory, explain what happens at each layer when you load a web page, and confidently answer "what layer does X operate at" for any common protocol or device.
