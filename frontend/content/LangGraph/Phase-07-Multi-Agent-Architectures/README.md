# Phase 7: Multi-Agent Architectures

## What You'll Learn

Architect and orchestrate enterprise multi-agent systems in LangGraph: build central supervisor routers that delegate tasks dynamically to specialized worker agents, construct hierarchical multi-tiered agent teams, and implement decentralized peer-to-peer network and swarm collaboration patterns.

## Learning Objectives

- Implement the Multi-Agent Supervisor pattern with function-calling router models.
- Build Hierarchical Agent Teams with mid-level managers and specialized subgraphs.
- Implement decentralized Peer-to-Peer agent handoffs and swarm communication protocols.
- Manage shared state and sub-agent state boundaries across collaborative agent graphs.
